
# TeamFlow

A full-stack productivity and team collaboration platform designed to help users organize projects, manage tasks, and work through a structured workspace.

## Overview

TeamFlow is a SaaS-style productivity application focused on project management, authentication, and team workflows.

The project includes a dashboard-based interface where users can manage projects, organize work, and access collaboration features.

It was built to practice full-stack application development, authentication, API integration, and database-driven workflows.

## Features

- User registration and authentication
- JWT-based authentication
- Protected routes
- Project management
- Task organization
- Team dashboard
- Chat and messaging interface
- Account center
- PostgreSQL database integration
- Responsive dashboard interface

## Technology Stack

### Frontend

- PostgreSQL

## Application Workflow

1. Users register or log in to the application.
2. Authentication is handled through the backend.
3. Authenticated users access protected dashboard routes.
4. Users can manage projects and organize tasks.
5. Users can access the messaging interface.
6. Account information can be viewed through the account center.

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm
- PostgreSQL
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/mayankgorshi/teamflow.git
```

Navigate to the project directory:

```bash
cd teamflow
```

Install the frontend and backend dependencies according to the project structure.

Configure the required environment variables for the backend, including the database connection and authentication configuration.

Run the development servers using the commands configured in the client and server package files.

### Environment Variables

Configure the required environment variables before running the application.

Typical configuration includes:

- PostgreSQL database connection
- JWT secret
- Backend port
- Frontend API URL

Never commit your actual secrets or private credentials to the repository.
